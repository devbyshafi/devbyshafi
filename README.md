# Raihan Shafi

**Developer & Designer at UnicodeIT · Dhaka, Bangladesh**

I design interfaces, build the systems behind them, and make tools for exploring scientific evidence. My work spans web, desktop and native Android, from the first interaction to the data and delivery workflows behind it.

## Design · Engineering · Research

**Interaction design.** I use typography, spacing and motion to make interfaces understandable and show people what changed.

**Software engineering.** I build across the interface and database, with attention to saved progress, clear delivery status and predictable retries. My web work includes React, TypeScript, Node.js and PostgreSQL.

**Research tooling.** I build tools for following a claim back to a paper, data record or molecular structure, with room to record what still needs checking.
